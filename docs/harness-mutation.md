The selected scope intentionally remains the two deterministic modules in `stryker.config.mjs`. Mutation score measures the exercised mutations in that scope; it does not establish correctness for the rest of the server or for values outside the declared input contracts.

After the tests above, the selected scope scored 92.22%: 83 of 90 mutants killed, 7 survived with the dispositions above, and none lacked coverage. The configured break threshold remains 80. A disposable configuration with a valid break threshold of 100 produced exit code 1 and the message `Final mutation score 92.22 under breaking threshold 100`, proving score failures propagate. Stryker rejects 101 during configuration validation because thresholds cannot exceed 100, so 100 is the strongest valid gate probe.
